# Live.City

**The live pulse of the world's cities** — local time, weather, 7-day forecast, air quality, news, earthquakes and live cams for 36 major cities, plus a free relocation-lead engine, sponsorships, donations, contests and careers.

Static site · no build step · GitHub Pages (main branch, root) · Google AdSense `ca-pub-6620975821265271`.

## Structure
| Path | Purpose |
|---|---|
| `index.html` | Home: live hero, world clocks, live city grid, relocation CTA |
| `cities.html`, `city.html?c=<slug>` | Directory + live city dashboard |
| `city/<slug>/` | Static SEO city pages (auto-generated by the workflow) |
| `live.html`, `compare.html` | Live world wall · city vs city |
| `relocate.html` | **Dedicated lead generation** (4-step form) |
| `advertise.html`, `support.html`, `contests.html`, `careers.html` | Sponsorship/partners · donations · contests & prizes · hiring |
| `guides/` | Original long-form guides (AdSense content) |
| `privacy.html`, `terms.html`, `disclaimer.html` | Legal + trademark/copyright disclosure |
| `data/cities.json` | City dataset — add a city here and push |
| `scripts/update_data.py` + `.github/workflows/update.yml` | Every 6h: refresh snapshot, regenerate city pages + sitemap |
| `BUILD-PROMPT.md` | Concept, revenue model, competitor research, phase-wise build prompt |

## Forms
All forms post via AJAX to FormSubmit. The destination address is assembled in `assets/js/core.js` at runtime and never appears in HTML. **First submission triggers a one-time activation email** from FormSubmit to the site inbox — click *Activate* once.

## Launch checklist
1. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
2. Point the Live.City DNS to GitHub Pages (A records `185.199.108.153`, `.109.153`, `.110.153`, `.111.153`; `www` CNAME → `webworksa1.github.io`), then set the custom domain in Settings → Pages and tick *Enforce HTTPS*.
3. AdSense → Sites → add `live.city` → request review. `ads.txt` is already in place.
4. AdSense → Privacy & messaging → enable the Google-certified CMP for EEA/UK/CH.
5. Optional: add PayPal / Buy Me a Coffee / Stripe links in `CFG.pay` in `assets/js/core.js` to show instant donation buttons.
6. Actions → *Refresh live data and city pages* → *Run workflow* once to generate the static city pages.
